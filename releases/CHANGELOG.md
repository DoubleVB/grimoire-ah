# Profitmancer: release notes

Format for each release: Discord post (below) = same text as the CurseForge changelog.
Build: `powershell -File scripts/build-release.ps1`, then upload `releases/curseforge/*.zip` on CurseForge.
GitHub: `releases/github/Profitmancer-WoW-Forever.zip` (served by `install.ps1`).

## 1.3.8

```
**Profitmancer 1.3.8** 🪙

**Minimap**
• More compact, easier-to-read tooltip
• New line: items listed on the AH (all characters) + total value
• Smaller red cooldown counter
• Round, centered yellow glow on the icon

**Recipe export**
• Export sends the recipe straight to your AH shopping lists
• Pop-up in the middle of the screen confirms it, same style as the cooldown notification
• Shift+click on Export: copy window for Auctionator
```
